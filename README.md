# Mind the Gap

Mój zeszyt do angielskiego przed maturą rozszerzoną. Czasy z osią czasu i wzorami, tłumacz, z którego słówka lecą prosto do fiszek, i ćwiczenia w stylu maturalnym. Działa jako aplikacja na telefonie (PWA), także bez internetu.

## Uruchomienie

```
npm install
cp .env.example .env.local
npm run dev
```

Przed commitem odpalam `npm run check` (typy, lint, testy).
